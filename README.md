# Chatbot Evaluation Dashboard 

Currently a work-in-progress! 

A dashboard made for the purpose of evaluating 
specific-purpose chatbots. 

# Final Version Goals 

- Bring your own model (accessible via API endpoint) and your own reference corpus. 
- Uses NLI, RAG, and similarity-comparison formulas to concretely evaluate metrics like truthfulness and consistency; never relies on an LLM-based judge
